# Governance Guide

## Pillars
1. **Policy as code**: enforceable, tested, versioned.
2. **Exception management**: time-bound, owned, reviewed.
3. **Vendor risk**: assessed, monitored, offboarded.
4. **Change management**: classified, approved, audited.
5. **Risk assessment**: continuous, owned, tracked.

## Cadence
| Activity | Frequency |
|---|---|
| Exception review | Weekly |
| Risk register review | Monthly |
| Policy test suite | Every commit |
| Vendor reassessment | Annually |
| Full risk assessment | Annually |
| Policy-as-code audit | Quarterly |

## Evidence for Auditors
- Policy files with git history.
- Exception register with approvals.
- Vendor assessment reports.
- Change tickets and approvals.
- Risk register with mitigations.
