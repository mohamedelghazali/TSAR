# Emerging Technology Guide

## AI Agents
- Sandbox per agent.
- Least privilege on tools.
- Human approval for irreversible actions.
- Memory isolation and TTL.
- Kill switch always available.

## Quantum
- CBOM inventory per release.
- Hybrid deployments now.
- Full migration by 2035.
- Crypto-agility in design.

## IoMT
- Unique identity per device.
- Encrypted PHI.
- Signed OTA updates.
- Segment network.
- Coordinated disclosure.

## Autonomous Systems
- Deterministic safety layer separate from ML.
- Sensor spoofing detection.
- Signed OTA with rollback.
- Remote kill switch with multi-party auth.
