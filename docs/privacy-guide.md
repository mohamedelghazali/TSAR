# Privacy Guide

## Principles
1. Minimize collection.
2. Limit purpose.
3. Retain only as long as necessary.
4. Protect by design.
5. Enable user control.

## Technologies
| Need | Tool |
|---|---|
| Pseudonymization | Token vault, HMAC-SHA-256 |
| Aggregate privacy | Differential privacy (OpenDP) |
| Analytics on encrypted data | Homomorphic encryption |
| Joint computation | Secure MPC |
| Distributed training | Federated learning |

## Verification
- Data inventory current.
- PIA/DPIA on file for high-risk.
- DSR fulfillment within SLA.
- Deletion propagated to backups.
- Consent state propagated.
