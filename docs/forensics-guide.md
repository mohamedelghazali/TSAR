# Forensics Guide

## Golden Rules
1. Do not alter the original.
2. Document everything.
3. Use verified tools.
4. Preserve chain of custody.
5. Analyze on copies.

## Workflow
1. Isolate the system (network, but preserve state).
2. Acquire volatile data first (memory, network, processes).
3. Acquire disk (write-blocker).
4. Hash and store.
5. Analyze on copies.
6. Report with evidence references.

## Legal
- Preserve evidence for potential litigation.
- Coordinate with legal counsel before acquisition if litigation is foreseeable.
- Maintain attorney-client privilege where applicable.
