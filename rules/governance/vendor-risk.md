# Vendor Risk Management

## Assessment
- Security questionnaire (SIG, CAIQ).
- SOC 2 Type II or ISO 27001 evidence.
- Penetration test summary.
- Data processing agreement.
- Sub-processor list.

## Data Handling
- Classification of data shared with vendor.
- Encryption in transit and at rest.
- Data residency requirements.
- Deletion on contract termination.

## Integration
- Vendor credentials rotated per policy.
- Vendor access scoped to minimum required.
- Vendor activity logged and monitored.
- No vendor write access to production without approval.

## Continuous Monitoring
- Annual re-assessment.
- Alerts on vendor security incidents.
- Review vendor security advisories.
- Test vendor offboarding annually.

## Forbidden
- Onboarding without security review.
- Vendor access without audit logging.
- Data sharing without DPA.
- Auto-renewal of contracts without re-assessment.
