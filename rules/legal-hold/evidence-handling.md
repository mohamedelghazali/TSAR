# Evidence Handling

## Chain of Custody
- Every item logged: ID, description, hash, custodian, transfer log.
- Physical: tamper-evident packaging.
- Digital: encrypted container, write-once storage.
- Signed handoffs; no gaps.

## Collection
- Follow rules/forensics/acquisition.md.
- Use validated tools.
- Document deviations.
- Witness for physical collection.

## Storage
- Access-controlled, encrypted, offline where possible.
- Redundant copy for high-value evidence.
- Periodic integrity verification.

## Presentation
- Preserve metadata (timestamps, file system attributes).
- Maintain original in unaltered state.
- Use copies for analysis and presentation.

## Forbidden
- Modifying original evidence.
- Access without logging.
- Storing evidence on general-purpose systems.
- Losing chain of custody documentation.
