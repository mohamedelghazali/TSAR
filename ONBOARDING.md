# TSAR Agent Onboarding

This is the entry point for AI agents receiving the TSAR repository link.

1. Read [Universal Agent Onboarding](docs/universal-agent-onboarding.md).
2. Follow [INSTALL.md](INSTALL.md) if shell execution and permissions are available.
3. Apply [AGENT_BOOTSTRAP.md](AGENT_BOOTSTRAP.md) only through the agent's documented persistent-instructions mechanism.
4. Check [COMPATIBILITY.md](COMPATIBILITY.md) for scope limitations.
5. Follow [VERIFY_INSTALLATION.md](VERIFY_INSTALLATION.md) and report observed results.

Canonical entry URL: https://github.com/mohamedelghazali/TSAR#install

A repository URL is not executable. Persistent adoption depends on the agent having repository access, tools, permissions, and a supported persistence mechanism.
