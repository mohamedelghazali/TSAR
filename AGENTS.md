3. For engineering and security work, consult the current `manifest.yaml`, core directives, and only the applicable domain rules.
4. Do not assume a repository-local instruction file creates global persistence in other projects.
5. Never claim installation, persistent configuration, verification, or compliance unless you performed and observed the corresponding steps.
